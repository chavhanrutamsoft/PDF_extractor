PDF Catalog Price Extractor

A Streamlit app that pulls catalog numbers and prices from selected pages of a PDF pricelist and exports the rows to Excel or CSV.

Page-targeted parsing

Pick single pages, comma-lists, or ranges (e.g. 16,18,20-25).

Configurable matching

Custom catalog regex, optional keyword filter, optional text fallback.

Clean output

Structured rows with reference, list price, and discount when present.

Run it locally

  1. Clone the repository and open the project directory.
  2. Install Python dependencies: 
    pip install -r requirements.txt
  3. Start the Streamlit app: 
    streamlit run app.py
  4. Open the URL Streamlit prints (default http://localhost:8501).
